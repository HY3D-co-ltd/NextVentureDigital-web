## 인터랙션 및 애니메이션

### Framer Motion 적용

| 요소 | 애니메이션 |
|------|-----------|
| 페이지 전환 | 페이드인 (`opacity: 0→1`, 300ms) |
| 섹션 진입 | `whileInView` fade-up (`y: 30→0, opacity: 0→1`) |
| 카드 호버 | `scale(1.02)` + 그림자 확대 |
| 숫자 KPI | 카운트업 (0에서 목표값까지) |
| 네비게이션 | 모바일 메뉴 슬라이드 + 오버레이 페이드 |
| 탭 전환 | 컨텐츠 페이드 트랜지션 |
| 로고 마퀴 | CSS 무한 스크롤 애니메이션 |
| 히어로 SVG | 미세한 패럴랙스 + 플로팅 도트 |

### 성능 고려사항
- `will-change` 속성으로 애니메이션 성능 최적화
- 이미지는 Next.js `Image` 컴포넌트 (정적 빌드 시 자동 최적화)
- 폰트: `display: swap`으로 FOUT 방지
- 불필요한 JS 번들 최소화
